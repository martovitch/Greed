# Greed — Automatic Modular & Baseline Grid for Adobe InDesign

**Greed** is a powerful ExtendScript (JSX) for Adobe InDesign that automates the creation of mathematically precise modular, baseline, and document grids. It features an interactive UI with a live preview and allows you to synchronize guides, margins, and typography in just a few clicks.

## Key Features

* **Interactive UI with Live Preview:** The script analyzes the active spread in real-time and displays a visual overlay of margins, modules, and grids directly within the panel.
* **Mathematically Precise Document Grid:** Automatically calculates intervals and subdivisions so the grid fits the page dimensions perfectly.
* **Smart Baseline Grid:** Syncs the baseline increment to vertical gridlines or their subdivisions.
* **Modular Grid:** Quickly generates columns and rows, calculating gutters so modules snap exactly to the gridlines.
* **Snap Margins:** Rounds margin values to align perfectly with the nearest gridlines or subdivisions.
* **Typography Generator:** Automatically creates 12 hierarchical paragraph styles (Headline, Subhead, Body Copy, Caption, etc.) with sizes and leading mathematically tied to your baseline grid.
* **Configuration Templates:** Save and load your specific grid settings using `.greed` template files.

## Installation

1. Download the `Greed.jsx` script file.
2. Open Adobe InDesign.
3. Go to **Window** > **Utilities** > **Scripts**.
4. In the Scripts panel, right-click the **User** folder and select **Reveal in Explorer** (Windows) or **Reveal in Finder** (macOS).
5. Copy the downloaded `Greed.jsx` file into the opened `Scripts Panel` folder.
6. Return to InDesign. The script will now appear in the panel. Double-click `Greed.jsx` to run it.
